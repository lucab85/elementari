# Elementari 📚

App Expo Go per aiutare i bambini della scuola elementare con i compiti.
Colorata, divertente, facile da usare — con il minimo di bottoni!

## 📱 Come usare

```bash
npm install
npx expo start
```

Scansiona il QR code con **Expo Go** sul telefono.

## 🎯 Materie e attività

### 🔢 Matematica (6 attività)
- **Tabelline** — Quiz a scelta multipla, tabelle dal 2 al 9, serie di risposte corrette 🔥
- **Addizioni e Sottrazioni** — Problemi casuali fino a 9999
- **Moltiplicazioni** — Difficoltà progressiva
- **Divisioni** — Risultati interi, 3 livelli di difficoltà
- **Trova il numero** — Trova il numero mancante nelle operazioni
- **Tabellone** — Tutte le tabelline da consultare

### 📖 Italiano (10+ attività)
- **Ortografia** — 7 argomenti: hanno/anno, hai/ai/ahi, ho/o/oh, ha/a/ah, c'è/ce, c'era/cera, qu/cu/cqu
- **Grammatica** — Verbo essere, verbo avere, singolare→plurale, articoli
- **Descrizione guidata** — 5 temi con domande guida per esercitarsi a scrivere
- **Poesie e Letture** — 5 poesie (Ada Negri, Gianni Rodari, Carducci) con domande di comprensione

### 🦕 Storia e Scienze
- **Animali del mondo antico** — 10 animali preistorici con curiosità e periodo
- **Quiz** — 15 domande a scelta multipla

### 🌍 Geografia
- **Regioni d'Italia** — Tutte le 20 regioni con capoluogo e curiosità
- **Quiz** — 15 domande su regioni, città e monumenti

### 🇬🇧 Inglese
- **Vocabolario** — 65+ parole in 6 categorie (colori, animali, cibo, famiglia, numeri, giorni)
- **Quiz** — Domande auto-generate inglese↔italiano

### 📝 I Miei Compiti
- Lista compiti giornaliera con salvataggio locale
- Tocca per completare, tieni premuto per eliminare

## 🎨 Design

- Colori vivaci e arrotondati
- Grandi aree touch, minimo di bottoni
- Animazioni divertenti (bounce, scale) per feedback
- ⭐ Sistema di stelle e serie
- Tutto in italiano

## 🛠️ Tecnologie

- React Native + Expo SDK 55
- expo-router (navigazione file-based)
- AsyncStorage (salvataggio locale)
- Animated API (animazioni)
