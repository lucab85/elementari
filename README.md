# Elementari - App Compiti 📚

App Expo Go per aiutare i bambini della scuola elementare con i compiti.
Colorata, divertente, facile da usare!

## Materie

- 🔢 **Matematica** — Tabelline, addizioni/sottrazioni, moltiplicazioni
- 📖 **Italiano** — Ortografia (hanno/anno, hai/ai/ahi, ho/o/oh, ha/a/ah), descrizione guidata
- 🦕 **Storia e Scienze** — Animali del mondo antico (flashcard + quiz)
- 📝 **I Miei Compiti** — Lista compiti giornaliera

## Come usare

```bash
npm install
npx expo start
```

Scansiona il QR code con **Expo Go** sul telefono.

## Tecnologie

- React Native + Expo SDK 55
- expo-router (navigazione file-based)
- AsyncStorage (salvataggio compiti)
- Animated API (animazioni divertenti)
